# 2026-09-24

## ノート19（著者実装の `'dynamic'` で κ と day 別遷移行列を学習）の方針

ノート18は `'standard'` → `'partial'`（σ=1）までで、κ と day 別の遷移行列は学習していない。ノート19では著者実装（[lenca56/dynamic_glmhmm](https://github.com/lenca56/dynamic_glmhmm)）の `'dynamic'` まで進める。自前実装は使わない。

### 前提（ノート18から引き継ぐもの）

- 対象は `VG1GC-66`、音提示試行2359件・14 day。入力は修正1（History を定常値から始める）後の `fixed` 入力 `[x_bias, x_hist_z, x_rew_z]`、観測は `yA`（1=No Reaction）。
- fold 分割は著者の `split_data(N, SESS, folds=5, blocks=10, random_state=1)`。N と `sessInd` だけで決まるので18と同一になる。
- 初期状態分布 π は一様固定（`fit_init_states=False`）。
- σ は18で選ばれた **σ=1（全状態・全列共通のスカラー）** を固定し、掃引しない。
- 状態数は **K=3 を先に実行**する。K=2 は別セクションに分け、K=3 の結果を見てから実行するか決める。

### κ（著者実装の引数名は `alpha`）が何をするか

day \(s\) の遷移行列の行 \(i\) は次式で更新される（論文 Methods の閉形式、`dynamic_glmhmm.py` 724行）。

\[
P^s_{ij} = \frac{n^s_{ij} + \kappa A_{ij}}{n^s_i + \kappa}
= \frac{n^s_i}{n^s_i+\kappa}\cdot\frac{n^s_{ij}}{n^s_i} + \frac{\kappa}{n^s_i+\kappa}\cdot A_{ij}
\]

- \(n^s_{ij}\) はその day の期待遷移回数（\(\zeta\) の和）、\(A\) は `partial` 段で得た全 day 共通の遷移行列。
- 各 day の遷移行列は「その day だけで数えた遷移確率」と「A」の加重平均で、day どうしは互いを参照しない（重みのような前後 day とのつながりは無い）。
- その day にほぼ現れない状態の行はほぼ A になる。18の解では状態2がほとんどの day で占有率0なので、その行は κ によらずほぼ A になる見込み。

著者の結果（IBL 32匹）は K=3・σ≈3.2・κ≈2。セッションごとの自己遷移確率は平均0.8前後で、系統的な変化は無く、急変は稀だった。学習による変化は主に重みと占有率に現れている。dynamic が partial をどれだけ上回ったかは本文に数値が無い。

### 著者実装をそのまま呼ぶと詰まる点と対処

1. **大域遷移行列 A の行和チェックで例外になる。** `fit(model_type='dynamic')` は A の行和が1から1e-3以上ずれると例外を投げる。`partial` の遷移行列更新は K=3 だと分母の擬似カウントが対角+12・非対角+21とずれて行が正規化されず、18の最終フィットでも行和が `[0.99931, 0.9999, 0.99806]`（3行目が判定に引っかかる）。
   - 対処: 著者コードは変更せず、呼び出し側で A を行正規化してから `fit_eval_CV_dynamic_model` に渡す。K=2 では分母が対角・非対角とも+11で一致するので、この問題は起きない。
2. **κ が小さいと、非対角の擬似カウントによる退化防止が効かない。** `'dynamic'` の更新は `priorDirP` を使わない（著者関数も `priorDirP=None`）。κ=0 は day 別の最尤推定そのもので、ノート17で吸収状態に退化したのと同じ条件になる。κ=1 でも非対角の擬似カウントは 0.01〜0.04 程度しかない。その day に一度も訪れない状態の行が 0/0 になって NaN を出すおそれもある。
   - 対処: κ=0 もグリッドに残して結果は表示するが、下記の退化チェックと NaN チェックを通らない κ は選択対象から外す。
3. **全データの最終パラメータで CV を初期化すると、テストデータが漏れる。** fold ごとの初期値は、同じ fold の `standard` / `partial` の解から作る。全データの最終パラメータから初期化するのは、全データでの最終フィットだけにする。

### 確認済みのこと

- 18の `partial` 最終フィットは、`maxIter=25` の打ち切りでも尤度の意味では収束している。続きから EM を回すと訓練対数尤度は −947.219 → −947.224 でほぼ動かず、10反復で停止した（重みは最大0.27動くが、`partial` に絶対的なアンカーが無いことによる平坦な方向）。検証スクリプトは `.claude/tmp_nb19_convcheck.py`。
- 全データ・K=3 の EM は1反復約1.2秒。著者実装は最低10反復回るので、1フィットあたり12秒以上かかる。

### 計算量を減らすための方針

PC は2コアなので fold の並列化はせず、逐次実行にする（並列にしても最大2倍で、実行中の PC がほぼ使えなくなる）。代わりに、次の工程を省いたり再利用したりする。

| 工程 | 扱い | フィット回数 |
| --- | --- | --- |
| fold ごとの `standard` | 18のキャッシュ（`std_fixed['fits']`）を再利用 | 0 |
| fold ごとの `partial` σ=1 | 18は学習したがキャッシュ（`sigA_fixed`、形状 (7, 5)）にtest対数尤度しか保存していないので学習し直す。`standard` 解から σ=1 へ直接学習し、18の温スタート（σ=1e-3→1e-2→0.1→1）は再現しない | 5 |
| 全データの `partial` σ=1 | 18のキャッシュ（`final_fixed['par']`）を再利用 | 0 |
| fold ごとの dynamic κ 掃引 | 著者の `fit_eval_CV_dynamic_model` をそのまま呼ぶ。κ=∞ は `partial` 解の評価だけなので学習しない | 6 κ × 5 fold = 30 |
| 全データの dynamic | κ=∞ から降順に温スタートし、選ばれた κ に着いたところで止める（それより小さい κ は学習しない） | 1〜6 |
| 退化チェック | 学習済みパラメータで前向き後向きを1回回すだけ | 0 |
| K=2 | 保留（K=3 の結果を見て判断） | 0 |

- `partial` を σ=1 へ直接学習するので、fold ごとの解は18と初期値が変わる。ノート19の中では κ=∞ の点（＝19で学習した `partial`）を基準に全 κ を比べるので、比較は19の中で閉じている。18の σ=1 のtest対数尤度（−0.4201 ± 0.0059）とSEの範囲で合うかだけ確認する。
- 反復上限は著者の200回のまま（通常は許容誤差で先に止まる）。最低10反復の制約は著者コードの仕様なので変えない。
- (fold, κ) ごとに結果を `data/cache/ver5_note19.pkl` に保存し、中断しても続きから再開できるようにする。再実行時はキャッシュを読むだけになる。
- κ=0 は降順の最後なので、そこで時間がかかったり NaN が出たりしても、他の κ の結果は残る。
- 実行は WSL の `.venv-wsl` で nbconvert をバックグラウンド実行する。見込みは K=3 全体で約10〜30分（`partial` 5回・dynamic 30回・最終フィット数回）。

### κ の選び方と退化チェック

κ はtest対数尤度（fold 平均±SE）だけで選ばない。次のチェックをすべて通った κ の中から、test対数尤度が最大のものを選ぶ。

- 状態別の day 内正規化位置（平均±sd）。ある状態が day の前半・後半に張り付いていないか。ノート17の退化解では 0.101±0.080 のように偏った。
- day 別の状態系列。全 day が同じ順序のセグメントに切られていないか。
- day 別遷移行列の対角が1に張り付いた行（吸収状態）が無いか。
- パラメータに NaN が無いか。

### 出力（K=3）

- κ ごとのtest対数尤度の表と図（κ=∞＝`partial` を基準線にする）。
- 各 κ の退化チェックの表。
- 選ばれた κ での全データフィットについて、18と同じ指標（1状態が90%以上の day の数、day 内の切り替え回数、run 長、\(P(z)\geq0.8\) の残存率、皮質デコードに使える試行数）。
- day 別の自己遷移確率の推移図（著者の Fig. 4F に相当）と、day 別の重みの推移図。

### K=2（余力があれば、別セクション）

- fold ごとに、K=3 の `partial` σ=1 解から状態を1つ除いて初期値にする（遷移行列はその行と列を削って行を正規化し、重みはその状態の分を捨てる）。除く状態は3通りの縮約パラメータそれぞれの訓練対数尤度を前向き計算1回で求めて選び、学習するのは選んだ1通りだけにする。
- そこから K=2 の `partial` σ=1 を学習し、K=3 と同じ κ 掃引をする。σ=1 は K=2 では CV し直さない（著者も `bestSigma` を K によらず固定している）。
- 全データでの K=2 最終フィットだけは、K=3 の全データ最終パラメータから同じ手順で初期化する。
- K=3 と同じ fold のtest対数尤度、状態構造、皮質デコードに使える試行数で比べる。
- 計算量は `partial` 5回 + dynamic 30回 + 最終フィット数回で、K=3 と同程度（K=2 は1反復あたりの計算が K=3 より軽い）。
