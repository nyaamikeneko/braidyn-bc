# 研究計画: マウス強化学習における脳-身体結合と内部状態遷移の解明

## 1. Research Questions (RQ)

### Main RQ
**マウスの強化学習におけるパフォーマンス向上は、皮質活動（中枢）と表情（末梢）の動的な結合（Coupling）の最適化によって説明できるか？**

本研究では、学習を単なる脳内表現の変化としてだけでなく、脳の意図（内部状態）が身体へ正確かつ遅延なく伝播し、同期するようになるプロセスとして捉え直し、そのメカニズムを解明する。

### Sub-RQs

#### RQ1: 内部状態の生物学的妥当性 (Biological Validity)
行動時系列のみからHMM（隠れマルコフモデル）で定義された「内部状態（Engaged vs Random）」は、皮質活動や表情データにおいても特異的なパターンとして実在するか？
* **目的:** 数理モデル上の潜在変数が、生理学的な実体を伴う現象であることを検証する。

#### RQ2: 学習による表現と結合の変容 (Learning Dynamics)
学習の進行に伴い、脳と身体の関係性はどのように変容するか？
* **情報の質の変化:** 皮質活動がエンコードする情報は、学習初期の「運動パラメータ」から、学習後期の「内部状態/文脈」へとシフトするか？
* **同期の強化:** 皮質状態と表情状態の間の「タイムラグ」は縮小し、相関（Coupling Strength）は強まるか？

#### RQ3: ミス試行の質的分解 (Error Mechanism)
ミス試行（Error Trials）の発生機序は、学習段階によって異なるか？
* **目的:** 全てのミスを同一視せず、脳と身体の「同期ズレ」の観点から質的に分類する。

---

## 2. Hypotheses (仮説)

### H1: 状態表現のシフト
学習初期の皮質活動はレバー引きなどの「運動」に強く相関するが、学習後期（Expert期）にはHMMで推定された「内部状態（Engaged/Random）」との相関が支配的になる。

### H2: 脳-身体カップリングの強化
学習が進むにつれて、皮質活動（中枢）から表情（末梢）への情報伝達ラグが減少し、両者の状態確率は高い同期性を示すようになる。

### H3: ミス試行の二重機序モデル
学習段階により、ミス試行の原因となるメカニズムが異なる。
* **学習初期 (Mismatch):** 脳は課題に従事（Engaged）しているが、身体制御が追いつかず乖離している状態。
* **学習後期 (Joint Disengagement):** 脳と身体が同期して非従事（Random）状態に遷移している状態（いわゆる「サボり」）。

---

## 3. Study Design (PICO)

| 項目 | 内容 |
| :--- | :--- |
| **Population (対象)** | レバー引き課題を行うマウス（学習初期 vs 学習後期） |
| **Exposure (要因)** | HMMにより推定された内部状態（Engaged State / Random State） |
| **Comparison (比較)** | ・学習段階間の比較（Novice vs Expert）<br>・モダリティ間の比較（皮質活動 vs 表情 vs 行動） |
| **Outcome (結果)** | ・状態デコーディング精度<br>・脳-表情間の時系列相関（Coupling Strength）とラグ<br>・ミス試行時の状態乖離度 |

---

## 4. Analysis Framework

1.  **Phase 1: Ground Truth Generation**
    * 行動ログ（正誤・反応時間）を用いたHMMによる状態推定。
2.  **Phase 2: Multimodal Decoding**
    * 皮質活動および表情データを用いた状態分類モデルの構築と精度検証。
3.  **Phase 3: Coupling Analysis**
    * 脳モデルと顔モデルの予測確率を用いた時系列相関解析（Time-lag analysis）。
4.  **Phase 4: Error Decomposition**
    * ミス試行における脳-身体乖離度の定量化とクラスタリング。
