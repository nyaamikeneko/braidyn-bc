# 研究計画: マウス強化学習における脳-身体結合と内部状態遷移の解明

## 1. Research Questions (RQ)

### Main RQ
**マウスが課題に上達するとは、行動の実行そのものの精緻化（運動学習）なのか、それとも「いつ従事すべきかを制御する」内的な状態調整能力の獲得なのか。後者だとすれば、学習の進行に伴い皮質活動が担う情報は瞬間の運動指令から抽象的な従事状態の表現へと重心を移し、かつその内的状態は表情によりいっそう忠実に映し出される（脳-身体の結合が強まる）ようになるか。**

内部状態（Engaged / Random）はIBL系譜のGLM-HMM文献（Ashwood et al. 2022, Mohammadi et al. 2025, Hulsey et al. 2024）が繰り返し扱ってきた枠組みで、運動学習（motor refinement）と関与制御の学習（engagement control）を区別する問いである。本研究はこの区別を、Day 1–15の学習過程を貫くデータで定量的に検証する。

### Sub-RQs

#### RQ1: 内部状態の生物学的妥当性 (Biological Validity)
行動＋表情から定義された内部状態（GLM-HMMの学習に一切使っていない皮質活動）から、独立にデコード可能か？
* **目的:** 数理モデル上の潜在変数が、学習に使っていないモダリティ（皮質）でも実体を伴う現象であることを検証する。
* **設計上の注意:** 表情はすでに状態を定義する側の入力に含まれているため、表情に対して同じ検証を行うと循環論法になる。皮質のみが独立検証に使える。

#### RQ2: 学習による表現と結合の変容 (Learning Dynamics) — 主軸
日をまたいで対応の取れた状態定義（Dynamic GLM-HMM、[docs/requirements_ver5.md](requirements_ver5.md)）のもとで、学習の進行に伴い脳と身体の関係性はどのように変容するか。
* **情報の質の変化:** 皮質活動が相関する対象は、運動的特徴（顔・身体の瞬間の動き）から内部状態的特徴（HMM状態自体・その事後確率、Action History/Reward Historyのような文脈変数）へとシフトするか？
* **同期の強化:** 状態確率（行動＋表情由来）と皮質デコード確率の間の「タイムラグ」は縮小し、対応の強さ（Coupling Strength）は増すか？
* **前提:** 現行の「日ごと独立学習」（`notebooks/14_glmhmm_ver4_trials.ipynb` / `16_glmhmm_ver4_faceB_alldays.ipynb`）は状態ラベルが日をまたいで対応しないため、この問いを定量検証できない。Dynamic GLM-HMMへの移行によって初めて検証可能になる。

#### RQ3: ミス試行の質的分解 (Error Mechanism)
ミス試行（Error Trials）の発生機序は、学習段階によって異なるか？
* **目的:** 全てのミスを同一視せず、脳と身体の「同期ズレ」の観点から質的に分類する。全task-dayをDynamic GLM-HMMで一貫して扱うことで、学習段階（前半/後半）別の統計検定が可能になる。

## 2. Hypotheses (仮説)

### H1: 状態表現のシフト
学習初期の皮質活動はレバー引きなどの「運動」に強く相関するが、学習後期（Expert期）にはHMMで推定された「内部状態（Engaged/Random）」との相関が支配的になる。ここでいう運動的特徴とは、顔・身体のPosition/Speed（瞬間の動き）のような、その試行の実行そのものを表す量を指す。内部状態的特徴とは、瞬間の運動とは独立な課題文脈についての「構え」——HMMの離散状態 $z_k$（またはその事後確率）と、History系入力（Action History / Reward History、現在の運動とは無関係に前試行の結果を持ち越す文脈変数）を指す。

### H2: 脳-身体カップリングの強化
学習が進むにつれて、皮質活動（中枢）から表情（末梢）への情報伝達ラグが減少し、両者の状態確率は高い同期性を示すようになる。

### H3: ミス試行の二重機序モデル
学習段階により、ミス試行の原因となるメカニズムが異なる。
* **学習初期 (Mismatch):** 脳は課題に従事（Engaged）しているが、身体制御が追いつかず乖離している状態。
* **学習後期 (Joint Disengagement):** 脳と身体が同期して非従事（Random）状態に遷移している状態（いわゆる「サボり」）。

## 3. Study Design (PICO)

| 項目 | 内容 |
| :--- | :--- |
| **Population (対象)** | レバー引き課題を行うマウス（Day 1–15の学習過程を貫く1個体内の軌跡） |
| **Exposure (要因)** | Dynamic GLM-HMMにより推定された内部状態（Engaged State / Random State）、日をまたいで対応するラベル |
| **Comparison (比較)** | ・学習日間の比較（Day 1–15の連続的な変化、Novice期 vs Expert期の端点比較を含む）<br>・モダリティ間の比較（皮質活動 vs 表情 vs 行動） |
| **Outcome (結果)** | ・皮質活動からの状態デコーディング精度（chance比）<br>・皮質デコード確率と状態確率の時系列相関（Coupling Strength）とラグ<br>・ミス試行時の状態乖離度 |

---

## 4. Analysis Framework

1. **Phase 1: Dynamic GLM-HMM学習**
   行動4次元＋表情9次元（13次元、[docs/requirements_ver5.md](requirements_ver5.md) 4節）を入力に、Day 1–15を貫くDynamic GLM-HMM（GLM重み・遷移行列がセッション間で緩やかに変化）を学習し、日をまたいで対応する状態ラベルと事後確率を得る。
2. **Phase 2: 皮質からの独立デコーディング**
   Phase 1で皮質を一切使わずに得た状態を目的変数とし、皮質活動（44 ROIのΔF/F）を入力とする正則化デコードモデルを構築・精度検証する。表情・行動の情報は混ぜない（リーク防止）。
3. **Phase 3: Coupling Analysis**
   状態確率と皮質デコード確率の時系列相関・タイムラグをtrial単位で算出し、Day indexに回帰して学習に伴う変化（H2）を検証する。
4. **Phase 4: Error Decomposition**
   全日データをプールし、学習段階（前半/後半）別にミス試行の脳-身体乖離度を定量化・分類する（H3）。
